# Data ethics and handling

Project NEURA treats provider-supplied neuronal recordings as research data with explicit provenance.

## Rules

1. Preserve the original dataset unchanged.
2. Record the source, date received, version and any provider terms.
3. Do not redistribute raw data unless the provider explicitly permits it.
4. Cite the data provider in publications, presentations and public research outputs where required.
5. Never commit access tokens, credentials or private download links.
6. Keep analysis reproducible: code and parameters should explain how derived outputs were produced.
7. Separate observations from interpretation and avoid unsupported biological or cognitive claims.

## FinalSpark

When FinalSpark data is used, FinalSpark should be acknowledged/cited as the data source according to the terms supplied with the dataset.

The repository's software licence does not grant rights to third-party datasets.
