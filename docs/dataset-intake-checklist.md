# Dataset intake checklist

When the FinalSpark dataset arrives:

- [ ] Save the provider email/terms separately.
- [ ] Record dataset name/version/date received.
- [ ] Keep original files unchanged in `data/raw/`.
- [ ] Record file sizes and checksums.
- [ ] Identify file formats.
- [ ] Find sampling rate and time units.
- [ ] Find voltage/signal units.
- [ ] Identify electrode/channel mapping.
- [ ] Identify stimulation/event markers, if present.
- [ ] Identify supplied spike timestamps or processed metrics, if present.
- [ ] Inspect a short recording before processing the entire dataset.
- [ ] Document any assumptions.
- [ ] Confirm what outputs may be published or redistributed.
